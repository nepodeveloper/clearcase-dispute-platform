## Implement
Add a SQLite outbox row with event ID, aggregate ID/version, versioned event type, safe payload, occurrence/correlation metadata, publication time and attempt count. Persist it with every dispute submission and processing transition. Add a background local publisher port/adapter; Kafka remains PR-18.
