# PR-16 — Optimistic concurrency and immutable history

**Batch:** Batch 03 — Financial reliability  
**Scope:** one PR only; do not start PR-17 automatically.  
**Outcome:** Make case transitions race-safe with a persisted version and retain append-only timeline/audit records.

## Implement
Add a SQLite `Version` concurrency token (initial value 1), include it in dispute responses, and accept optional `expectedVersion` on local simulation commands. A stale version returns 409 `dispute.concurrencyConflict` before transition work; EF's compare-and-swap predicate protects concurrent writes. Keep case, version, timeline and existing audit writes in the same transaction. PostgreSQL remains deferred.

- [x] Stale update fails safely
- [x] History is append-only
- [x] No state change without its timeline/audit entry
